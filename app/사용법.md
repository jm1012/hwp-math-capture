# 수식 캡처 → 한글 붙여넣기 사용법

설치: 루트 README의 "설치" 또는 "소스에서 실행"을 참고하세요.

## 쓰는 법
1. `수식캡처.bat` 더블클릭 → 작업 표시줄에 **수식 캡처** 창이 생기고, 오른쪽 아래에 "준비 완료" 알림 (모델 로드 약 10~30초)
2. `Ctrl+Shift+Q` → 화면이 어두워지면 수식 부분을 드래그 (Esc: 취소)
3. 1~2초 뒤 "복사됨" 알림 → 한글에서 `Ctrl+V` → 수식 개체로 붙음
   - 다른 프로그램(메모장 등)에 붙이면 LaTeX 글자로 붙음
4. 끄기: 작업 표시줄의 **수식 캡처** 창을 열고 [종료], 또는 창 닫기(X). 두 번 실행하면 "이미 실행 중" 안내가 뜸

## 단축키 바꾸기
- 작업 표시줄의 **수식 캡처** 창 → **단축키 변경** 버튼 (트레이 아이콘 메뉴에도 있음) → 칸을 클릭하고 원하는 키 조합을 누름 → 저장
- 저장하면 바로 적용되고 다음 실행에도 유지됨 (`config.json`에 저장)
- Ctrl, Alt, Win 중 하나를 포함해야 함 (F1~F24는 단독 가능). Ctrl+C/V 같은 기본 단축키는 막아 둠
- 다른 프로그램이 이미 쓰는 조합이면 알려 주고 기존 단축키를 유지함
- "기본값" 버튼으로 Ctrl+Shift+Q 복원

## 설정 파일
- 인식 기록: `history.log`, 오류: `error.log`

## 알아둘 점
- 인식 정확도는 인쇄체 기준 약 73%. 틀리면 붙여넣은 수식을 더블클릭해 한글 수식 편집기에서 고치면 됨
- 손글씨는 아직 시험 안 함
