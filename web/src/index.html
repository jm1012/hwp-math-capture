변환

    PDF 가 여러 개면 하나씩 차례로 변환해 PDF 마다 한글 파일을 따로 만듭니다. 변환이 끝난 PDF 는 다른 PDF 가 변환되는 동안에도 내려받을 수 있습니다.

    문제 확인

      왼쪽에서 문제를 고르세요.

      키보드 ← → 로도 넘길 수 있습니다. "확인할 문제(⚠)만"을 켜면 ⚠ 문제만 넘깁니다.

      Windows 프로그램 (exe)

      같은 인식 엔진을 쓰는 Windows 프로그램도 있습니다. 컴퓨터에 따라 웹 버전보다 빠를 수 있고, 아래 기능이 더 있습니다.

      • 화면의 수식·문제를 드래그해 바로 한글에 붙여 넣기 (수식 캡처 Ctrl+Shift+Q, 지문 캡처 Ctrl+Alt+J)
      • 문제 확인 창에서 고친 문제 하나만 한글로 복사

      최신 exe 받기 (GitHub Releases) → hwp-math-capture-windows.zip

      설치와 주의사항
      1. zip(약 380MB)을 받아 원하는 폴더에 압축을 모두 푼 뒤 수식캡처.exe 를 실행하세요. zip 안에서 바로 실행하면 동작하지 않습니다. 설치나 인터넷 연결은 필요 없습니다.
      2. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요. 코드 서명이 없는 무료 프로그램이라 뜨는 경고이고, 한 번 실행하면 다시 뜨지 않습니다. 압축을 풀기 전에 zip 파일 속성에서 차단 해제에 체크해도 됩니다.
      3. Windows 10/11 용이고, 한글 2020 에서 시험했습니다. 다른 한글 버전은 아직 시험하지 않았습니다.
      4. 오른쪽 아래에 "준비 완료" 알림이 뜨면 쓸 수 있습니다. 끌 때는 작업 표시줄의 수식 캡처 창에서 [종료]를 누르세요.

      꼭 읽어 주세요

      • 변환 결과는 반드시 검토하세요. ⚠ 표시는 영역이 잘못 나뉜 경우는 잘 잡지만, 수식 속 숫자 하나가 틀린 것 같은 작은 오류는 잡지 못합니다.
      • 글자 정보가 없는 스캔 PDF 는 더 느리고 덜 정확합니다. 표는 아직 한글 표가 아니라 그림으로 들어갑니다.
      • 본인이 쓸 권리가 있는 자료만 변환하세요.
      • 변환 중에는 이 탭을 닫지 마세요. 새로 고치면 변환 결과와 문제 확인 내용이 사라집니다(받아 둔 모델은 남음).
      설정과 안내

      처음 한 번 인식 모델(약 270MB)을 받아 브라우저 저장소에 둡니다. 다음부터는 바로 시작합니다. 모델은 Hugging Face에서, 프로그램은 이 사이트에서 받습니다.

      Windows용 프로그램(exe)과 같은 인식 코드를 브라우저 안에서 돌립니다. 결과는 같지만 속도는 컴퓨터와 브라우저에 따라 exe보다 느립니다. Chrome·Edge 최신판을 권합니다.
