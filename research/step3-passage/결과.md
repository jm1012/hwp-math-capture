# v2 실험: 글자 + 수식 지문 인식

## 구성 (app/passage.py)
1. 수식 위치 검출: Pix2Text MFD 1.5 (문장 속 수식 / 따로 쓴 수식)
2. 수식 박스에 끼어든 한글 글자는 잘라냄 (OCR 글자 위치 + 박스 끝 한 글자 재인식)
3. 수식 부분을 흰색으로 가리고 한글 OCR: PaddleOCR PP-OCRv5 한국어 (검출 5MB + 인식 13MB)
4. 수식 조각 인식: Pix2Text MFR 1.5 (torch 없이 onnxruntime 으로 직접 실행)
5. 위치로 줄을 묶고, 줄바꿈된 문장은 한 문단으로 합침. 보기 번호(①~⑤), 한 글자 변수(l, m) 보정

## 합성 문제 24장 (problems.py 12문제 × 나눔명조/나눔고딕)
| 단계 | 한글 글자 오류율 | 수식 정답 |
|---|---|---|
| 수식 박스 그대로 가리고 OCR + texify | 14.2% | 29% |
| 박스에서 한글 잘라내기 + Pix2Text MFR + 후처리 | **7.1%** | **44%** |

수식 정답은 문제 속 모든 `$…$`(숫자 하나짜리 포함)가 표기 차이를 무시하고 일치한 비율.

## 실제 시험 문제 캡처 10장 (수능/모의고사형, 저작권 때문에 저장소에는 넣지 않음)
- 잘 됨: 문장 속 수식, 분수·로그·극한·적분·시그마, 구간별 함수(cases), 보기 ①~⑤, [4점]
- 문제당 2.5~6초 (이 실험 서버 CPU 기준, 수식이 많은 긴 문제는 12초)
- 남은 문제: 조건 상자 안 내용, (가)(나)(다) 빈칸 상자, ㉠㉡ 기호, 띄어쓰기 일부 누락(위의점), 가끔 수식 끝 한글 한 글자가 수식에 섞임

## 수식 하나 인식 (1단계 시험 세트 48장, 같은 채점 기준)
| 모델 | 정답 | 시간 |
|---|---|---|
| texify (v1) | 35/48 (73%) | 1.2초 |
| Pix2Text MFR (1단계 측정) | 30/48 (63%) | 0.5초 |
| **Pix2Text MFR + 표기 정리 (v2)** | **37/48 (77%)** | 0.4초 |

`\underset{k=1}{\overset{n}{\sum}}` → `\sum_{k=1}^{n}`, `\root 3 \of` → `\sqrt[3]`, `\mathop{=}` → `=` 같은 Pix2Text 고유 표기를 정리하니 texify 보다 나아짐 (app/latex_fix.py).
